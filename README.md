# LiPaste

LiPaste is a Firefox extension that allows you to paste PGN into Lichess Analysis.

## Installation

1. Clone the repository
2. Open Firefox and navigate to `about:debugging`
3. Click on "This Firefox"
4. Click on "Load Temporary Add-on"
5. Select the `manifest.json` file in the repository
6. The extension should now be loaded and ready to use

## Usage

1. Click on the extension icon in the Firefox toolbar
2. Paste your PGN into the popup
3. Click "Submit"
4. Extension will open a new tab with a Lichess Analysis of the PGN
